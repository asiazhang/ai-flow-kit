## 目标

找出远程跟踪分支已删除的本地分支。删除前展示完整候选列表并请求确认；默认使用安全删除，包含未合并提交的分支会保留。

## 执行流程

### 1. Preflight：同步并发现候选

保持目标 Git 仓库为当前工作目录，使用当前已加载 Skill 的目录作为 `<skill-dir>`，执行：

```bash
bash "<skill-dir>/scripts/discover-gone.sh"
```

脚本会刷新所有远程的远程跟踪分支，并输出 `GONE_BRANCHES` 区段。候选必须来自 `refs/heads/`，且每个候选的 upstream 状态为 `[gone]`。如果当前分支本身在候选中，脚本会停止；没有候选时根据 `SUMMARY_STATUS` 报告“本地仓库没有需要清理的失效分支”并结束。

同步失败时报告错误并停止，不使用可能过期的分支状态。脚本不删除分支。

**完成条件**：已成功获得完整候选列表；当前分支不在候选列表中；无候选时已停止且未执行删除。

### 2. Delete gate：确认删除范围

展示完整候选列表并请求用户确认。确认内容必须说明：

- 影响的是本地分支，不会恢复远程分支；
- 默认执行 `git branch -d`；
- 包含未合并提交的分支会删除失败并保留；
- 不会自动改用 `git branch -D`。

用户拒绝时报告候选列表并停止，不执行删除。

**完成条件**：用户确认了当前完整候选列表；确认范围没有扩大。

### 3. Action：重新校验并安全删除

用户确认后，在新的 Bash 调用中，将确认列表中的每个实际分支名作为独立参数传入：

```bash
bash "<skill-dir>/scripts/delete-confirmed.sh" \
  --expected-branch '用户确认的第一个实际分支名' \
  --expected-branch '用户确认的第二个实际分支名'
```

执行前必须替换为实际分支名，不得保留中文示例值；没有第二个分支时删除第二行。脚本会重新刷新并发现候选，只有候选列表与所有 `--expected-branch` 完全一致时才执行 `git branch -d -- "$branch_name"`。列表变化时脚本以非零状态停止，回到 Delete gate；不执行任何删除。

删除失败时保留分支并记录原因。只有用户之后明确指定某一个分支并再次确认强制删除时，才允许手工执行 `git branch -D -- "$branch_name"`；强制删除前先展示该分支相对 `HEAD` 的未合并提交。

**完成条件**：每个确认分支都有成功或失败结果；失败分支未被强制删除；候选变化时未发生删除。

### 4. Verify：复查结果

`delete-confirmed.sh` 会输出 `VERIFY` 区段。确认成功删除的分支已不存在，删除失败的分支仍保留，当前分支没有变化。

**完成条件**：复查结果与逐项删除结果一致。

### 5. Report：汇报

分别列出：

- 安全删除成功的分支；
- 因未合并提交而保留的分支；
- 用户确认后强制删除的分支；
- 其他删除失败及原因；
- 当前分支。
